# Skill 测试与验证记录

本文件记录 `make-knowledge-cards` 技能在开发阶段的实测过程。测试方法：严格按 `SKILL.md` 的 Workflow 处理三篇不同类型的输入，逐项核对 Step 5 自检清单，再据此修订技能指令。

## 测试 1｜科普类 Markdown（概念与机制密集）

输入：`tests/science_sleep_memory.md`（睡眠与记忆，约 430 字，含铺垫性开头和总结性结尾）

产出：

```markdown
# 知识卡片：睡眠如何帮助记忆

> 来源：tests/science_sleep_memory.md

## 卡片 1｜记忆巩固是短期记忆转为长期记忆的过程，主要在夜间完成
- **核心知识**：记忆从短期存储转为长期存储的过程叫记忆巩固，它主要发生在夜间睡眠中。
- **简明解释**：白天获取的新信息最初只是暂时存放，关键的巩固步骤留在睡眠期间完成，之后才形成较持久的存储。
- **例子 / 自测问题**：文中把哪一种过程称为"记忆巩固"？它主要在什么时段进行？

## 卡片 2｜慢波睡眠中的海马体重放建立稳定连接
- **核心知识**：慢波睡眠阶段，大脑把新学信息的神经活动模式重新播放给大脑皮层，建立更稳定的连接。
- **简明解释**：白天的新信息暂时存放在海马体，夜间由大脑重放给皮层，这一步是记忆得以稳定的关键机制。
- **例子 / 自测问题**：按文章描述，暂时存放新信息的脑区是哪里？重放发生在哪个睡眠阶段？

## 卡片 3｜两种睡眠阶段对记忆类型的分工不同
- **核心知识**：慢波睡眠主要巩固事实性知识和空间记忆，快速眼动睡眠更多参与情绪性记忆和程序性技能。
- **简明解释**：文章指出两个阶段的分工不同，并强调两者缺一不可，不能互相替代。
- **例子 / 自测问题**：若要巩固一组事实性知识，文章指出主要依赖哪个睡眠阶段？

## 卡片 4｜睡眠被压缩会打断重放，熬夜复习难以稳定记忆
- **核心知识**：睡眠被压缩后重放过程被打断，即使增加复习遍数，记忆也难以稳定下来。
- **简明解释**：熬夜减少了夜间重放的机会，多看几遍材料无法替代这一步，因此熬夜复习往往得不偿失。
- **例子 / 自测问题**：根据文章，为什么"熬夜多背几遍"不能让记忆稳定下来？

## 卡片 5｜完整睡眠周期比临考前延长复习时间更有效
- **核心知识**：学习后保证完整的睡眠周期，比临考前延长复习时间更有效。
- **简明解释**：这是文章由前述机制得出的实践结论：既然巩固依赖睡眠，投入时间睡觉的收益高于挤压睡眠去复习。
- **例子 / 自测问题**：学完新内容后，按文章建议应优先保证什么？
```

自检结论：5 张，落在目标区间；无语义重复；所有事实均可回溯原文；"很多人以为睡觉只是让大脑休息"这一铺垫开头和最后一段的总结性表态被识别为噪声或并入已有卡片，未单独成卡。卡片 1 合并了"定义"与"发生时段"两个紧密关联的事实，卡片 4、5 分别保留"机理后果"与"实践策略"，避免了注水式拆分。

## 测试 2｜方法论类 TXT（规则与误区）

输入：`tests/method_pomodoro.txt`（番茄工作法，约 480 字，含两类打断和多条操作规则）

产出：

```markdown
# 知识卡片：番茄工作法

> 来源：tests/method_pomodoro.txt

## 卡片 1｜番茄工作法的时间结构
- **核心知识**：选定一项任务专注 25 分钟，随后休息 5 分钟；每完成四个番茄钟，休息 15 到 30 分钟。
- **简明解释**：这是该方法的基本操作节奏，把工作与休息切分成固定长度的段落。
- **例子 / 自测问题**：按文中规则，完成四个番茄钟后应休息多长时间？

## 卡片 2｜作用机制是降低任务启动难度
- **核心知识**：番茄工作法通过 25 分钟的边界降低启动难度，让人更容易着手庞大的任务。
- **简明解释**：文章指出拖延往往不是因为任务难，而是因为看起来庞大；短时间边界让任务变得可以开始。
- **例子 / 自测问题**：文中认为人们拖延任务的主要原因是什么？

## 卡片 3｜内部打断：记下念头并继续当前番茄钟
- **核心知识**：自己想起别的事属于内部打断，做法是先在纸上记下来，继续当前番茄钟。
- **简明解释**：这类打断来自自身，记录可以保住念头而不中断计时，不必立刻切换任务。
- **例子 / 自测问题**：计时中突然想起一封要回的邮件，按文中分类属于哪种打断？应如何处理？

## 卡片 4｜外部打断：中止并重来，不接着算
- **核心知识**：由别人或环境造成的打断若无法避免，应中止当前番茄钟，处理完重新开始，不要接着算。
- **简明解释**：文章把这类打断与内部打断区别处理，关键是不要把一个被切断的番茄钟继续计入。
- **例子 / 自测问题**：同事临时打断且无法避免时，原来的番茄钟该怎么处理？

## 卡片 5｜番茄钟数量不等于产出
- **核心知识**：番茄钟的数量不等于产出，为凑数量而挑琐碎任务或回避深度工作会让方法失去意义。
- **简明解释**：文章强调该方法管理的是注意力而不是工时统计，因此不能把完成的番茄钟数量当成成果指标。
- **例子 / 自测问题**：为了保持计时完整而避开需要深度思考的工作，为什么违背了文中观点？

## 卡片 6｜休息是方法的一部分，不能跳过
- **核心知识**：休息不是奖励而是方法的一部分，跳过休息会让后续番茄钟质量下降。
- **简明解释**：文章把休息纳入方法本身，省略休息削弱的是整个流程的效果，而非仅仅少了一点放松。
- **例子 / 自测问题**：连续工作、跳过 5 分钟休息，按文章说法会带来什么后果？
```

自检结论：6 张，无重复；内部与外部打断各自成卡而非合并，因为二者是可独立记忆的操作规则；"核心做法很简单"这类修饰语未成卡；所有解释均来自原文，未补充番茄工作法的外部背景（如起源、适用人群等原文未提的信息）。

## 测试 3｜短文章（信息不足，检验不凑数）

输入：`tests/short_caffeine.md`（咖啡因，约 140 字，仅少数事实）

产出：

```markdown
# 知识卡片：咖啡因的作用

> 来源：tests/short_caffeine.md

原文信息量有限，仅提炼出 3 张卡片。

## 卡片 1｜咖啡因通过阻断腺苷受体减轻困意
- **核心知识**：咖啡因抢占腺苷受体，使疲倦信号无法传递，从而减轻困意。
- **简明解释**：腺苷在清醒期间逐渐积累，与受体结合会让人疲倦；咖啡因占据受体位置后，这一信号传不下去。
- **例子 / 自测问题**：按文中机制，腺苷与受体结合会让人产生什么感觉？

## 卡片 2｜咖啡因效果因人而异
- **核心知识**：咖啡因的效果与基因、耐受度和服用时间有关，个体差异明显。
- **简明解释**：文章列出三个影响因素，说明同一种摄入方式对不同人可能产生不同效果。
- **例子 / 自测问题**：文中提到哪三个因素影响咖啡因的效果？

## 卡片 3｜下午晚些时候摄入可能干扰夜间睡眠
- **核心知识**：下午较晚摄入咖啡因，可能干扰夜间睡眠。
- **简明解释**：这是文章给出的时间相关注意事项，与效果受服用时间影响这一事实直接相关。
- **例子 / 自测问题**：按照文章，什么时间摄入咖啡因需要注意可能影响睡眠？
```

自检结论：仅 3 张并附说明，没有为凑到 5 张而编造内容或拆分同一机制；卡片 3 的解释中出现了未翻译的英文词 "closely linked"，这是产出瑕疵，已通过修订 SKILL.md 的输出规范提醒修正（见下）。

## 测试 4｜不支持的输入类型（规则检验）

模拟请求："帮我总结这个 PDF / 这个网页链接 https://example.com/article 做知识卡片"。

预期行为：明确说明暂不支持 PDF 与网页抓取，请用户粘贴正文或提供本地 `.md`/`.txt` 文件；不尝试下载、解析或用其他方式绕过。SKILL.md 的 "When to Use" 段落已覆盖该情形。

## 发现的问题与修订

1. **拆分粒度存在灰色地带**：测试 1 中"定义 + 发生时段""机制后果 + 实践策略"容易被拆成四张单薄卡片来凑数。已在 Step 2 补充判别规则：紧密关联的事实合并成一张，机制与由其推出的策略可以分开。
2. **输出语言一致性**：测试 3 的首轮产出出现了中英混杂措辞（英文短语直接嵌进中文解释）。已在输出规范中补充：输出语言跟随原文主要语言，保持全篇一致；不要在中文输出里夹杂未翻译的英文词。修订后的测试产出已同步改正。
3. **来源与自测题的可回溯性**：测试 2 的自测题均可在原文中找到答案，符合规则，无需修订。
