# 睡眠如何帮助记忆

很多人以为睡觉只是让大脑休息，其实睡眠参与了记忆的形成过程。

记忆从短期存储变成长期存储的过程，叫做记忆巩固。研究发现，这个过程主要在夜间睡眠中完成。白天新学的信息暂时存放在海马体里，到了夜间，大脑会在慢波睡眠阶段把这些信息的神经活动模式重新播放给大脑皮层，从而建立起更稳定的连接。

睡眠的不同阶段分工不同。慢波睡眠主要帮助事实性知识和空间记忆的巩固，而快速眼动睡眠更多参与情绪性记忆和程序性技能的整理。两种阶段缺一不可。

这也解释了为什么熬夜复习往往得不偿失。睡眠被压缩之后，重放过程被打断，即便多看了几遍材料，记忆也难以稳定下来。相比之下，学习后保证完整的睡眠周期，比临考前延长复习时间更有效。

因此，安排学习计划时应该把睡眠当成学习的一部分，而不是学习的对立面。
