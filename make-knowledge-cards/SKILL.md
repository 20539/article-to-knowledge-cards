# Make Knowledge Cards

## Overview

将一篇文章压缩成一组可用于复习的知识卡片。每张卡片只承载一个知识点，所有内容忠实于原文，不引入外部信息。输出为 Markdown，便于直接阅读或导入笔记工具。

## When to Use

在以下情形启用本技能：

- 用户粘贴文章正文，并要求做成知识卡片、学习卡片、复习卡片。
- 用户给出本地 `.md` 或 `.txt` 文件路径，并要求提炼知识点。
- 用户使用"总结成卡片""把这篇文章拆成卡片""提炼考点"等等价表述。

不处理下列输入：网页 URL 抓取、PDF 解析、生成 Anki 牌组文件、图形界面操作。遇到此类请求，明确说明不支持，并请用户粘贴文本或提供 `.md`/`.txt` 文件；不要尝试用其他方式绕过。

## Input Handling

1. 粘贴文本：直接将其作为唯一输入源，无须读取文件。
2. 本地文件路径：仅接受 `.md` 与 `.txt`（大小写不敏感）。用文件读取工具读取全文；读取失败、文件为空或编码无法识别时，说明情况并停止，不臆测内容。较长文件须通读全文后再提炼，不得只看开头或结尾。
3. 同时提供粘贴文本与文件路径：以用户明确指定的来源为准；未指明时先询问。
4. 其他格式或 URL：按上述"不支持"规则处理。

## Workflow

### Step 1 — 通读并盘点核心主张

通读全文，列出文章真正想传达的核心主张（通常 3-8 条）。优先纳入：

- 在开头、结尾反复出现或被强调的结论
- 支撑结论的关键机制、原理、因果链
- 重要的概念定义、分类、对比
- 明确的方法、步骤、成立条件
- 关键数据与研究结论

主动忽略：修辞与过渡句、背景铺垫、举例中的次要细节、情绪表达，以及广告、版权、导航等噪声。

### Step 2 — 拆分为单一知识点

把候选主张拆到"一卡一事"的粒度。判断标准：能用一句完整的话说清核心，且不再包含并列的子主张；若一句话里出现两个独立主张，拆成两张卡。

语义去重：同一观点在文中多次出现或换了一种说法，只保留表述最完整的一张卡；已被某张卡覆盖的细节点不再单独成卡。

判别示例：定义与其发生时段、同一机制的前提与结果，属于紧密关联的事实，合并成一张；机制本身与由该机制推出的实践策略，可以分成两张。若拆开后某张卡需要反复引用另一张才能讲清，说明拆得过细，应合并。

### Step 3 — 排序

按文章原有的论述顺序排列卡片。文章没有明显顺序时，按"概念 → 机制 → 应用或结论"排列，确保基础概念出现在依赖它的卡片之前。

### Step 4 — 撰写卡片

每张卡片严格包含四个字段：

- **标题**：指向具体知识点（例："遗忘在学习后立即开始且先快后慢"），不用"引言""背景""小结"一类空泛标题。
- **核心知识**：一句话陈述原文的关键断言，作为记忆锚点。
- **简明解释**：2-4 句，把核心知识讲清楚。只能重组、浓缩原文已有信息，禁止补充原文没有的事实、数据或观点。
- **例子或自测问题**：原文有贴切例子时，用原文的例子（可精简措辞，不改变事实）；原文没有合适例子时，出一道自测问题，其答案必须能在原文中找到。不要为了填满这一栏而编造场景。

### Step 5 — 输出前自检

逐项核对：

- 每张卡是否只讲一个知识点？
- 卡片之间是否存在语义重复？
- 每个事实是否都能在原文中找到依据？
- 是否把推理或常识误当成原文陈述？
- 数量：目标 5-8 张。原文信息只够 3 张，就输出 3 张，并注明"原文信息量有限，仅提炼出 N 张"；不得注水凑数。原文要点超过 8 个时，合并相近项或保留最重要的 8 个。

## Output Format

用 Markdown 输出，遵循以下骨架：

```markdown
# 知识卡片：<文章主题>

> 来源：<用户粘贴的文本 / 文件路径>

## 卡片 1｜<具体标题>
- **核心知识**：<一句话>
- **简明解释**：<2-4 句>
- **例子 / 自测问题**：<原文例子或自测题>

## 卡片 2｜<具体标题>
- ...
```

少于 5 张时，在标题下方加一行说明。原文没有可靠标题时写"知识卡片：未命名文章"，不要编造标题。输出语言跟随原文的主要语言，全篇保持一致。

## Common Pitfalls

- 把文章的结构（"第一段讲背景""最后总结"）当成知识点。
- 标题写成"核心概念""重要观点"这类空壳。
- 把原文的举例本身当成一张独立卡片。
- 在解释里加入"众所周知""一般来说"之类的外部常识。
- 信息不足时硬凑到 8 张，或把同一观点换个标题重复出卡。

## Example

输入节选：

> 艾宾浩斯用无意义音节做实验，发现遗忘在学习之后立即开始，而且先快后慢。他绘制的曲线显示，学习后 20 分钟遗忘约 42%，一天后约 66%，一个月后约 79%。因此复习应该及时，在大量遗忘之前进行。

输出：

```markdown
## 卡片 1｜遗忘在学习后立即开始且先快后慢
- **核心知识**：遗忘在学习之后立即开始，进程先快后慢。
- **简明解释**：艾宾浩斯用无意义音节实验发现，遗忘并非均匀发生，最初阶段遗忘最快，之后逐渐放缓。
- **例子 / 自测问题**：根据文中曲线，学习后 20 分钟与随后一个月相比，哪个阶段遗忘比例增长更快？

## 卡片 2｜复习应安排在大量遗忘之前
- **核心知识**：及时复习能在大量遗忘发生前巩固记忆。
- **简明解释**：既然遗忘先快后慢，拖到遗忘严重后再复习，付出的代价更高；因此应把复习安排在遗忘加速的早期。
- **例子 / 自测问题**：为什么"学完隔一周再复习"不符合文中给出的结论？
```
