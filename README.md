# make-knowledge-cards

把一篇文章变成一组可直接复习的知识卡片：一张卡片只讲一个知识点，内容忠于原文，不编造、不凑数。

## 1. 项目解决什么问题

读完一篇文章想复习，自己做卡片耗时；直接让模型总结又容易出三类问题——把"第一段讲背景"这类文章结构当成知识点、一张卡片塞进多个主张、为了凑够数量编造原文没有的内容。

本项目把这些约束写进技能指令，让模型按固定流程提炼：通读盘点核心主张 → 拆成单一知识点 → 排序 → 写卡 → 输出前自检。产物是结构化 Markdown，可直接阅读或导入笔记工具。

## 2. 主要功能

- **两种输入**：用户直接粘贴文章正文；或给出本地 `.md` / `.txt` 文件路径（扩展名大小写不敏感）。
- **结构化卡片**：默认 5-8 张，每张含标题、核心知识、简明解释、例子或自测问题四个字段。
- **质量约束**：只提取重要知识；一卡一事；语义重复的合并；解释只重组、浓缩原文信息；原文没有合适例子时改用自测题，且答案须能在原文找到。
- **不凑数**：原文信息不足时，输出少于 5 张并注明"原文信息量有限，仅提炼出 N 张"；要点超过 8 个时合并相近项或只保留最重要的 8 个。
- **可追溯**：输出开头标注来源（粘贴文本或文件路径），卡片按原文论述顺序排列。
- **明确边界**：不处理网页 URL 抓取、PDF 解析、Anki 牌组生成和图形界面操作；遇到这类请求会提示用户改用粘贴文本或 `.md`/`.txt` 文件。
- **语言**：输出语言跟随原文主要语言，全篇保持一致。

技能包只含 `SKILL.md`（指令与工作流程）和 `agents/openai.yaml`（Codex 界面元数据），不含脚本，不依赖外部工具。

## 3. 安装方法

把 `make-knowledge-cards/` 整个目录复制到所用客户端的技能目录：

```bash
# WorkBuddy（用户级技能）
mkdir -p ~/.workbuddy/skills
cp -r make-knowledge-cards ~/.workbuddy/skills/

# OpenAI Codex
mkdir -p ~/.codex/skills
cp -r make-knowledge-cards ~/.codex/skills/
```

复制后的结构应为 `技能目录/make-knowledge-cards/SKILL.md`。当前仓库中的目录是待分发的技能包，尚未安装到任何客户端。

## 4. 使用方法

安装后直接提出需求，技能会按描述自动触发；也可显式使用 `$make-knowledge-cards` 调用。

常见说法：

- "把下面这篇文章做成知识卡片："（后接粘贴的正文）
- "把 `article.md` 提炼成复习卡片"
- "这篇文章有哪些考点？做成卡片给我"

输入处理规则：

- 粘贴文本直接作为唯一输入源。
- 本地文件仅接受 `.md` 和 `.txt`；读取失败、文件为空或编码无法识别时，技能会说明并停止，不臆测内容；较长文件会通读全文后再提炼。
- 同时给出粘贴文本和文件路径时，以用户明确指定的来源为准；未指明时先询问。

## 5. 输入输出示例

### 示例 A：粘贴文本

输入节选：

> 艾宾浩斯用无意义音节做实验，发现遗忘在学习之后立即开始，而且先快后慢。他绘制的曲线显示，学习后 20 分钟遗忘约 42%，一天后约 66%，一个月后约 79%。因此复习应该及时，在大量遗忘之前进行。

输出：

```markdown
# 知识卡片：艾宾浩斯遗忘曲线

> 来源：用户粘贴的文本

## 卡片 1｜遗忘在学习后立即开始且先快后慢
- **核心知识**：遗忘在学习之后立即开始，进程先快后慢。
- **简明解释**：艾宾浩斯用无意义音节实验发现，遗忘并非均匀发生，最初阶段遗忘最快，之后逐渐放缓。
- **例子 / 自测问题**：根据文中曲线，学习后 20 分钟与随后一个月相比，哪个阶段遗忘比例增长更快？

## 卡片 2｜复习应安排在大量遗忘之前
- **核心知识**：及时复习能在大量遗忘发生前巩固记忆。
- **简明解释**：既然遗忘先快后慢，拖到遗忘严重后再复习，代价更高；因此应把复习安排在遗忘加速的早期。
- **例子 / 自测问题**：为什么"学完隔一周再复习"不符合文中结论？
```

### 示例 B：短文章（信息不足时不凑数）

输入全文：

> 咖啡因通过阻断腺苷受体来减轻困意。腺苷是大脑在清醒期间逐渐积累的物质，它与受体结合会让人感到疲倦；咖啡因抢占了受体位置，疲倦信号就传不下去。咖啡因的效果因人而异，与基因、耐受度和服用时间有关。下午晚些时候摄入，可能干扰夜间睡眠。

输出：

```markdown
# 知识卡片：咖啡因的作用

> 来源：用户粘贴的文本

原文信息量有限，仅提炼出 3 张卡片。

## 卡片 1｜咖啡因通过阻断腺苷受体减轻困意
- **核心知识**：咖啡因抢占腺苷受体，使疲倦信号无法传递，从而减轻困意。
- **简明解释**：腺苷在清醒期间逐渐积累，与受体结合会让人疲倦；咖啡因占据受体位置后，这一信号传不下去。
- **例子 / 自测问题**：按文中机制，腺苷与受体结合会让人产生什么感觉？

## 卡片 2｜咖啡因效果因人而异
- **核心知识**：咖啡因的效果与基因、耐受度和服用时间有关，个体差异明显。
- **简明解释**：文章列出三个影响因素，说明同一种摄入方式对不同人可能产生不同效果。
- **例子 / 自测问题**：文中提到哪三个因素影响咖啡因的效果？

## 卡片 3｜下午晚些时候摄入可能干扰夜间睡眠
- **核心知识**：下午较晚摄入咖啡因，可能干扰夜间睡眠。
- **简明解释**：这是文章给出的时间相关注意事项，与效果受服用时间影响这一事实直接相关。
- **例子 / 自测问题**：按照文章，什么时间摄入咖啡因需要注意可能影响睡眠？
```
